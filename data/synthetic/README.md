# Synthetic data

Fairhaven Metrics LLC is a fictional B2B SaaS company. Nothing in this folder is a client, employer, or personal financial record.

| File | What it is |
| --- | --- |
| `Fairhaven_Metrics_FP&A_Model_SYNTHETIC_built.xlsx` | Workbook. Inputs are values. Forecast, Budget-vs-Actual, and Summary are formulas. |
| `test_cases.md` | Twelve checks rendered from the Python model. `fpa-model verify` recomputes them from the workbook inputs. |

Do not use these files in a live finance process.
